# 🎄 Новогоднее письмо-стикер для МАКС Мессенджера ✉️

Интерактивная новогодняя открытка-стикер в виде запечатанного письма для **Мессенджера МАКС** (max.ru).

---

## 🎁 Что внутри

1. **Интерактивный WebApp / Mini-App (`index.html`, `style.css`, `app.js`)**:
   - ✉️ **3D-стикер-конверт** с сургучной печатью Деда Мороза.
   - ❄️ **Падающий снег** и плавная анимация вскрытия сургуча и вылета письма.
   - 📜 Вопрос: **«Что ты хочешь на Новый год? 🎁»**
   - ✍️ Поле для ввода своего желания + большая золотая кнопка **«Понял» 🎅**.
   - 🎉 **Салют из конфетти** и праздничный звон колокольчиков (без внешних файлов, через Web Audio API).
   - 📱 Полная поддержка **MAX Bridge SDK (`window.WebApp`)** и мобильных телефонов.

2. **Готовый модуль для чат-бота МАКС (`bot-letter-handler.ts`)**:
   - Совместим с вашим ботом в папке `Downloads/max` (работает с `platform-api2.max.ru`).
   - Отправляет закрытое письмо в чат ➔ по нажатию на инлайн-кнопку «✉️ Открыть письмо» бот редактирует сообщение на раскрытое письмо с вопросом ➔ по нажатию на кнопку «Понял» (или если человек напишет в чат «Понял») подтверждает принятие желания!

---

## 🚀 Как запустить и посмотреть прямо сейчас

### Способ 1: Открыть в браузере
Просто дважды кликните на файл `index.html` или откройте его в браузере (например, Yandex или Chrome).

### Способ 2: Опубликовать на GitHub Pages (как проект `svs`)
1. Создайте репозиторий на GitHub (например, `max-ny-letter`).
2. Загрузите файлы `index.html`, `style.css`, `app.js`.
3. В настройках репозитория (Settings ➔ Pages) включите **GitHub Pages** (Branch: `main`).
4. Полученную ссылку вставьте в бота МАКС через кнопку `link` или `open_app`!

### Способ 3: Добавить в существующий бот МАКС
Скопируйте `bot-letter-handler.ts` в `Downloads/max/src/handlers/` и подключите в `message.handler.ts` и `callback.handler.ts`.
